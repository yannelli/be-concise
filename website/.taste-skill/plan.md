Complete marketing and documentation website for Concise. Individual Claude Code and Codex users first, team setup second. User selected Astro, Cloudflare Workers repository deployment, a straightforward product site, and Linear/Raycast/Resend as the craft bar. Existing plugin stays unchanged.

## Inventory
1. The name is a direct instruction: concise.
2. The mark combines three input paths into one short output.
3. Source assets use charcoal #18191D and orange #FF4A24.
4. Pending additions are checked before they land, rather than rewritten after a save.
5. Comment limit 2 lines; new-file limit 300 lines.
6. GitHub inline body limit 1 prose paragraph / 3 sentences per paragraph; structured headings and lists allowed.
7. Two hosts share one hook set.
8. AI-writing and dash checks are optional and disabled by default.
9. Eight presets and 44 categories.
10. The agent gets an exact location and limit; two denied retries do not block forever.
11. Full test output survives at /tmp/claude-test-last.log.
12. MIT, source and reference docs available; no customer/adoption proof.

## Argument
Hero: prevent agent verbosity before it lands -> interactive pending-write / hook / rewritten-addition example.
Guardrails: exact limits apply only to added material -> four actual diagnostic fragments (comment, file, PR and test output).
Use cases: useful in code review, docs, shared repos and cloud sessions -> specific workflows and links.
Installation: two hosts, no config for core checks -> exact commands and trust prerequisites.
Configuration: keep control -> editable preset selector, real JSON, opt-in style checks and escape hatches.
Documentation: reference depth already exists -> local rendered docs for installation, config, categories, environment and packs.
FAQ: practical constraints are explicit -> source-backed answers.
Close: install or inspect the MIT source -> real destinations.

## Copy deck
Hero: Your agent. Less verbose.
Supporting: Concise catches verbose comments, oversized files, and padded PRs before Claude Code or Codex writes them.
Action: Install Concise. Secondary: View source.
Proof note: Open source. MIT licensed. Core checks work without config.
Guardrails heading: Catch it before it lands.
Comment limit: Two lines. Not a lecture. A comment block over 2 lines gets a concrete denial and a chance to be rewritten.
File limit: Keep new files focused. New files over 300 lines are flagged before creation. Edits scan additions, not old content.
PR limit: A pull request, not an essay. Inline gh bodies allow one prose paragraph and up to 3 sentences per paragraph. Headings and lists are welcome.
Tests: Find the failure. Keep the log. Filter supported test-runner output before it reaches the agent; keep the full log on disk.
Use cases: Less to sift through. Code reviews; technical writing; shared repositories; cloud agents. Each has real supporting content and a documentation link.
Installation: Two commands. Then get back to work. Host-specific commands and trust notes; prerequisites visible.
Configuration: Your rules. Your exceptions. Optional style checks, eight presets, config JSON, targeted ignores and soft fail.
Docs: Go as deep as you need. Installation, configuration, 44 categories, environment and custom packs.
FAQ: A few useful answers. Defaults, rewrites, false positives, scope, Codex caveats, local execution.
Close: Keep the useful part. Install Concise; read the source. Made by Ryan Yannelli. MIT licensed.
