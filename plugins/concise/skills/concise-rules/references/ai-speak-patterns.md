# AI speak patterns, part 1

Adapted from avoid-ai-writing by Conor Bronsdon (MIT) and Ryan Yannelli's house rules.

Categories `vocabulary`, `wordiness`, `transitions`, `filler`, and `hedging`. The other 9 categories are in [ai-speak-patterns-2.md](ai-speak-patterns-2.md). What to do with a deny is in [avoid-ai-speak.md](avoid-ai-speak.md).

Every pattern is case-insensitive and word-boundaried. The left column holds the flagged text, the right column holds the replacement the hook prints.

## vocabulary

Presets: `default`, `ryan`, `technical`, `all`. The `technical` preset allows `robust`, `comprehensive`, `seamless`, `ecosystem`, `leverage`, `facilitate`, `underpin`, and `streamline`.

## transitions

Presets: `default`, `ryan`, `technical`, `all`.

| Flagged | Fix |
|---|---|
| `Moreover`, `Furthermore`, `Additionally` (sentence-initial) | cut, or "and", "also" |
| `In today's` X | name the context or cut |
| `In an era where`, `In an era of` | cut |
| `In the evolving world of`, `In the rapidly evolving world of`, `In the changing field of`, `In the rapidly changing field of` | lead with the point |
| `worth noting`, `It's worth noting that`, `It is worth noting` | state the fact |
| `Notably` (sentence-initial) | cut |
| `Here's what's interesting`, `Here's what caught my eye`, `Here's what stood out`, `Here's the interesting part` | state the fact |
| `When it comes to` | name the thing |
| `That said`, `That being said` | cut, or "but" |
| `Importantly`, `Interestingly`, `Surprisingly` (sentence-initial) | cut |
| `Certainly`, `Undoubtedly`, `Without a doubt` | cut |

## hedging

Presets: `ryan`, `ste`, `all`.

| Flagged | Fix |
|---|---|
| `perhaps` | cut, or commit |
| `could potentially`, `may potentially`, `might potentially` | can, or cut |
| `may eventually`, `could eventually` | say when |
| `might possibly`, `could possibly` | can, or cut |
| `potentially` (bare) | cut |
| `to be clear` | cut |
| `Note that` (sentence-initial) | cut, state the fact |
| `keep in mind`, `keep in mind that` | cut, state the fact |
| `generally` | cut, or name the exception |
| `typically` | cut, or name the exception |
| `in some cases`, `in many cases`, `in most cases` | name the case |
| `in general` | cut |
| `arguably` | cut, or commit |
| `somewhat` | cut, or measure |
| `to some extent` | cut, or measure |
| `it could be argued`, `it may be said`, `it might be argued` | state the claim |
